# Citizen skin sources

The five PNG files in this directory are selected, unmodified source skins from
**Minetest Skins Pack 1**, created by **isaiah658** and released under **CC0**.
Credit is optional under the license, but retained here as appreciation and provenance.

- Source page: https://opengameart.org/content/minetest-skins-pack-1
- Download: https://opengameart.org/sites/default/files/minetest_skins_pack_1.zip
- Original files: farmer `Skin_1.png`, laborer `Skin_3.png`, miner `Skin_14.png`,
  trader `Skin_28.png`, builder `Skin_32.png`
- Retrieved: 2026-08-19

`tools/gen-textures.js` converts these legacy 64x32 skins into Minecraft's modern
64x64 player-skin layout. The converted resources remain CC0 derivatives.
